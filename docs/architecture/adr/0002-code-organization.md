# ADR-0002：按职责组织代码，保留行为

日期2026-11-15，状态：已采纳，依据负责人当日明确授权。

不要求逐文件复制技术参考。允许合并过细文件、调整模块内目录和消除必要重复；不削减完整范围，不改变主要执行链、协议/权限/版本/租约语义。

当前取舍：Config、Load和简单校验同一config.go；healthz暂内联在router.go；cmd/server/main.go负责装配，run.go负责监听/关闭。避免为单字段环境读取引入通用env包，也不把所有启动/业务代码堆进main。后续职责增长再拆分。

调整必须说明参考/原位置到目标位置的映射、理由、依赖影响与行为验证；测试按模块/契约归组。该授权不等于助手可直接代写全部生产Go。
