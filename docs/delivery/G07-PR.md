## 问题与结果

关联 ENG-016、ENG-017、ENG-018，覆盖 FR-04 的工具管理与 REST 执行、FR-07 的 Agent 工具调用及 FR-17 的业务查询切片。客服 Agent 能在同一轮读取独立 Crossborder 服务的订单与库存，页面可实时看工具状态，刷新后可回读调用和结果。

## 实现范围

- 工具版本、Schema、凭据加密、端点白名单、试跑与指定版本发布。并发追加在数据库锁内校验所用基础版本，旧配置返回 HTTP 409。
- Agent 快照固定工具版本。Eino ADK 负责调用，SSE 报告工具事件，会话事务保存消息及工具主记录与版本 ID。未知工具保留失败轨迹。
- Crossborder 是独立 Go 模块和 HTTP 进程，使用独立 PostgreSQL 数据库。Go CI 增加业务模块检查。
- 平台迁移 000012–000013，独立业务库迁移 000001–000002。上线前需配置工具目标主机允许列表和凭据主密钥。

## 验证与边界

- 平台 `make check` 及 Crossborder 依赖一致性、Go race、vet、构建在隔离 PostgreSQL 环境通过。平台使用一次性 Redis。
- 桌面 Chrome 验证试跑、发布、快照绑定、订单与库存双工具、刷新回读及下一轮历史回放。业务 HTTP 和数据库为真实隔离服务，模型使用本地替身。
- 独立 AI 工作区预审的三个问题已修复并复核。GitHub 的 Documentation、Go、Web 检查和提交复审将在本 PR 核对。
- 沙箱、MCP/A2A 和敏感写操作分别随 G08、G09、G12 交付。默认知识库 SDK 执行器随 G10 装配。

## 回滚

如需回退，先回滚应用版本，停止新工具入口的写入并保留数据库。迁移回退涉及工具注册与试跑记录的删除，应在备份和核对数据后单独决定。

验收明细见 `docs/delivery/G07-VERIFICATION.md`。
