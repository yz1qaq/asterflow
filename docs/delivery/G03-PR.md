# G03 模型配置

Closes #13.

为当前工作空间增加模型供应商账户、部署计价、方案版本与环境绑定。React 管理端可以配置并回读 dev、staging、prod 各自的版本与限额。

- 供应商 API Key 由独立主密钥加密，账户列表只报告密钥状态；Base URL 拒绝查询参数。Gin 将鉴权后的空间信息传给 Service。
- 方案与首版在同一事务创建；后续追加使用行锁分配版本号。环境指向指定版本，改价与环境绑定按空间加锁；已有正预算的环境依赖某部署时，不能把该部署的两项常规单价同时清零。
- PostgreSQL 迁移000003至000005。开发库实查 version=5 dirty=false。回退000005会删除环境绑定和限额记录，保留方案及版本。

验证：本地 make check 在显式 PostgreSQL 测试配置下通过，包含 Go race、vet、构建、62项 Web 测试与构建。SQLC 重生成一致。桌面验证环境独立保存与回读、空间隔离、Viewer 只读、改价冲突时保留原价和原绑定。详见 `docs/delivery/G03-VERIFICATION.md`。

模型 Gateway、实际调用与运行期限额执行在后续需求组接入。独立 AI 工作区预审已复验；提交后的远程 CI 和实际 head 复审待确认。
